# Circuito no Wokwi

[diagram.json](diagram.json) é o circuito do Localfy (ESP32, OLED, microSD, 4 botões,
potenciômetro de volume e LED do modo Web) para o simulador [Wokwi](https://wokwi.com).

Para abrir: crie um projeto ESP32 em https://wokwi.com/projects/new/esp32 e cole este
arquivo na aba `diagram.json`. O estágio de alimentação (bateria, TP4056, chave e
MT3608) não existe no Wokwi e está em [../pcb/LIGACOES.md](../pcb/LIGACOES.md).
